# Auto centers on the site: VDP nearby row + hub pages (web side)

Companion to `bestest-pipeline/auto-centers/PLAN.md` (the pipeline computes everything nightly; this repo only renders).
Nothing here changes the live site until the pin bump at the end.

## Files in this PR

| File | What |
|---|---|
| `js/nearby-row.js` | Reads the server-rendered `[data-bst-nearby]` element, adds 5-8 car cards from the public feed under it, patches `containedInPlace` into the page's Car JSON-LD seller. No edits to existing `js/` files. |
| `css/nearby-row.css` | Styles for the row and cards (`bst-nr-*` only). |
| `data/auto-centers.json` | The curated center list (slug, name, dealers, centroid) the script loads from the same jsDelivr pin. Generated by `python3 auto_centers.py --export` in the pipeline repo; edit the YAML there, not this file. |
| `embeds/vdp-nearby-row.html` | The HTML Embed for the VDPs Template (the server-rendered contract). |
| `embeds/vdp-auto-center-schema.html` | Note only: why the seller -> Place schema is added by the script, not an embed (field cap). |

## The contract

The template renders (from CMS fields, no JS):

```html
<div class="bst-nr" data-bst-nearby data-dealer="Tustin Toyota" data-city="Tustin" data-segment="Compact SUV" data-slug="2023-toyota-rav4-xle-123456">
  <p class="bst-nr-text">Also at the Tustin Auto Center: 10 more Bestest-approved compact SUVs at Tustin Toyota, Tustin Kia
  and 2 other dealers. All at the same auto center as this RAV4, so you can see and drive them back to back.
  <a class="bst-nr-link" href="/auto-centers/tustin-auto-center">See them all</a></p>
</div>
```

`nearby-row.js` then fetches the feed and `data/auto-centers.json`, re-derives the same tier the pipeline used
(1 same segment at the center, 2 any car at the center, 3 same segment in the dealer's city, 4 any car in the city,
both needing a second dealer in the pool, 5 same segment within 3/6/10 miles), and inserts
`<div class="bst-nr-cards">` with up to 8 `<a class="bst-nr-card">` cards. Under 5 candidates: no cards, the sentence
stays. The center comes from `data-dealer` matched (case-insensitive) against the dealer lists in `data/auto-centers.json`;
an optional `data-center-slug` or `data-cars="slug,slug,..."` wins over the derivation (neither is written today).

Events (GA4, when `gtag` exists): `nearby_row_shown {tier, center, cards}`, `nearby_card_click {tier, center, href}`.

## What Jason does in Webflow (VDPs Template)

1. **CMS fields on VDPs** (plain text): `nearby-row-text`, `nearby-row-url` only. The collection is at Webflow's
   60-custom-field cap; on 11/2 the dead `redirect-target` and `vdp-slug` fields were removed to make room. The center
   slug and name stay in Airtable (Inventory `auto_center_slug` / `auto_center_name`) but are not pushed.
   `webflow_push.py` maps the two fields once `AUTO_CENTERS_WRITE=1`.
2. **Embed**: add an HTML Embed above the similar-cars rails with the contents of `embeds/vdp-nearby-row.html`;
   conditional visibility: `nearby-row-text` is set.
3. **Schema**: nothing in Webflow; `nearby-row.js` patches `containedInPlace` into the Car seller (see
   `embeds/vdp-auto-center-schema.html` for why).
4. **Include** (template footer custom code, after the vdp.js line; `defer` so it never blocks):

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/ShopBestest/bestest-web@<SHA>/css/nearby-row.css">
<script defer src="https://cdn.jsdelivr.net/gh/ShopBestest/bestest-web@<SHA>/js/nearby-row.js"></script>
```

   `<SHA>` is the commit on `main` after this PR merges (same pin bump routine as every other module; jsDelivr serves
   by commit SHA, so a branch cannot change the live site). The data file is read from the same pin, so one bump
   moves script, styles and data together. Staging can point elsewhere with `window.BS_AUTO_CENTERS_URL`.

## Hub pages (/auto-centers/{slug})

A new CMS collection **Auto Centers**, collection slug `auto-centers`, filled by `webflow_push.py` from the Airtable
table of the same name (`AUTO_CENTERS_WF_CID` + `AUTO_CENTERS_AT_TABLE`). Fields and bindings:

| Field (slug) | Type | Bind to |
|---|---|---|
| `name` | Plain text | item name ("Tustin Auto Center, Tustin") |
| `slug` | Slug | URL |
| `center-name`, `kind`, `city`, `street` | Plain text | optional chips / breadcrumb |
| `h1` | Plain text | the page H1 |
| `page-title`, `meta-description` | Plain text | page settings title / description |
| `intro` | Plain text | optional lead paragraph (also the first `<p>` of body-html) |
| `body-html` | Rich text | the main column (h2, p, ul, li, a, strong only) |
| `json-ld` | Plain text | page settings head custom code: `{{json-ld}}` (it is already a full `<script type="application/ld+json">` block, under 9,500 chars) |
| `dealer-count`, `car-count` | Number | optional stat line |
| `date-modified` | Date | "Updated" line / sitemap |
| `lat`, `lng` | Number | optional map |

Breadcrumb suggestion: Home > Auto centers > {h1}. Add `/auto-centers/` to the sitemap and to `llms.txt` once live
(a one-line list of the 18 hubs; not in this PR, since the pages do not exist yet).
